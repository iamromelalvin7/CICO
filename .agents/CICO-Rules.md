# CICO — Build Rules (Non-Negotiable)

- No emojis anywhere in the UI or code. Use SVG icons exclusively.
- Stay strictly within scope. Do not add features, screens, or behavior that were not explicitly requested. Do not guess or hallucinate requirements; ask if something is unclear.
- No mistakes: double-check logic, data handling, and UI states before considering a task done.
- Security first: never hardcode or leak secrets, API keys, or credentials in code or commits; use environment variables and keep them out of version control.
- Follow any design markdown files and reference images provided exactly; they take precedence over improvisation.
